# dsh-drawioedit

[English](README.md) | 中文

将上游 draw.io 编辑器裁剪并集成到 DeepSeek Harness Web 侧边栏，支持离线编辑 `.drawio` 图表，并将改动自动保存回原文件。

插件列表的显示名称与介绍支持英文和中文，随 Harness 语言设置显示，英文为默认回退；英文名称为去掉 npm scope 的原包名，中文名称说明用途，安装仍使用不变的真实包名。

![侧栏编辑器中打开的 .drawio 图表](docs/example.png)

## 安装

```sh
npx @deepseek-ai/dsh plugin --profile web add @guowenzhang/dsh-drawioedit
```

安装后重启宿主。

## 本插件做了什么

- **侧栏集成**：将上游编辑器接入 DSH 文件树和侧栏标签页，直接编辑工作区中的 `.drawio` 文件，中文文件名可正常显示，无需另开在线编辑器或上传图表。
- **包体积裁剪**：移除服务端 Java 资源、未压缩开发源码、专业图形库及相关图标和模板，重建精简图形包并清理模板索引，保留常用绘图能力；裁剪后的本地包**压缩后约 12.1 MB，解包后约 42.7 MiB**（`npm pack --dry-run`，已发布版本可能不同）。
- **自动保存实现**：打通编辑器与宿主文件服务，检测图表变化并自动写回打开的原文件，不再依赖手动导出、下载后覆盖。保存请求串行执行，等待期间只保留最新改动；写入成功后更新编辑器的已保存状态。
- **权限与冲突保护**：保存遵循当前会话的工作区权限，并使用文件版本校验，避免静默覆盖编辑期间被 agent 或其他程序修改的文件；权限拒绝、版本冲突及其他保存失败会在标签页提示。
- **离线运行**：随包提供编辑器资源，关闭云端集成，启动时不会加载第三方服务。

## 使用

1. 从文件树打开一个 `.drawio` 文件，进入侧栏编辑器。
2. 编辑图表，改动会自动保存回原文件；可在编辑器中查看已保存状态。
3. **Save / Ctrl+S** 可手动触发保存，**Save As** 在原目录重命名文件，**Export as** 下载副本。

## 保留图形与限制

保留通用与基本图形、箭头、流程图、ER、UML、BPMN、DFD、C4，以及自由绘图和草图样式。云厂商、网络设备等专业图形库未随包提供；依赖它们的图表可能显示异常。
